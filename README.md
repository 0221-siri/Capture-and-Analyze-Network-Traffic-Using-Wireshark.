Capture and Analyze Network Traffic Using Wireshark

 Objective:
To capture live network packets and identify basic network protocols and traffic types.

Tool Used:
- Wireshark
- PCAPdroid (for packet capture, if applicable)

Procedure:

1. Started network packet capture on the active Wi-Fi interface.
2. Generated network traffic by browsing websites.
3. Captured network packets for approximately one minute.
4. Stopped the packet capture.
5. Analyzed the captured packets.
6. Identified different protocols such as DNS, TCP, and HTTPS/TLS.

Protocols Identified:

1. DNS
Used for resolving domain names into IP addresses.
2. TCP
Provides reliable communication between devices.
3. HTTPS/TLS
Provides encrypted communication for web traffic.

Result:

Network traffic was successfully captured and analyzed. 
DNS, TCP, and HTTPS/TLS traffic were identified from the captured packets.

Conclusion:

This task provided practical experience in network packet capture, protocol identification, and basic network traffic analysis using packet-capture tools.
